D.I.S.C.O Preliminary Program V7.14 INTEGRATED STABILITY

설치 순서
1. Supabase SQL Editor에서 supabase_schema_v7_14_REQUIRED.sql 전체 실행
2. 이 폴더 전체를 GitHub Pages에 업로드
3. 모든 기기에서 강력 새로고침 또는 PWA 재실행

주요 변경
- 관리자 노트북에서만 2차 명단 최종 확정 및 2차 채점 열기
- 져지 태블릿은 round_phase 변경을 감지해 자동으로 새 명단 동기화
- 점수 미완료 상태의 강제 진행 완전 제거
- 져지별 서버 저장 완료 인원과 누락 참가자 표시
- 10명 점수 업로드 후 서버 값을 다시 조회해 저장 검증
- 저장 실패 자동 재시도 및 기기 임시 점수 유지
- 2차 전환을 Supabase 함수 1회 호출로 처리하여 중간 실패 시 전체 롤백
- 동시 관리자 전환은 PostgreSQL advisory lock으로 직렬화
- 랜덤 A/B/C 서클 배정, 엑셀, 이미지 ZIP 기능 통합
- 저장 중 새로고침 경고 및 마지막 서버 확인 시간 표시

행사 당일 진행
- 져지: 점수 입력 → 10명 검토 → CONFIRM & UPLOAD만 사용
- 관리자: 모든 져지 서버 저장 완료 확인 → 명단 편집 → 최종 확정 버튼 1회
- 져지 태블릿에서 2차 열기 버튼을 누를 필요 없음
